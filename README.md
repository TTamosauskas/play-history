# Play History

Player musical histórico de 800 a 2026, publicado em https://ttamosauskas.github.io/play-history/.

A versão 6.7.0 usa uma distribuição modular estática. O repositório preserva o catálogo histórico como fonte de build, aplica os deltas curatoriais da v6.6.1 e gera `_site` com `index.html`, CSS, catálogo compacto e quatro módulos JavaScript: aplicação, serviços, player e bootstrap.

O build valida 1.726 faixas, unicidade dos IDs de YouTube e regressões curatoriais essenciais antes do deploy.
